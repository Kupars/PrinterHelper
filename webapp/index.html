MIXED FILE PRINT HELPER

混合文件双面打印助手

适合像 HP LaserJet P1007 这种没有自动双面的打印机。你可以一次上传多个文件，支持 PDF、图片、Word、PowerPoint、TXT、RTF 和 ZIP。工具会先自动转成 PDF， 再合并成一个总文件，最后生成两份双面打印结果： 第一份给第一次打印，第二份给第二次回纸打印；用于第二次打印的 PDF 默认不翻转，且已自动倒序，并会在需要时自动补充空白页。 合并时不会做拼版，每个原始 PDF 页面仍然单独占一页纸面；如果上一个文件是奇数页， 会自动补空白背页，保证下一个文件从新纸张正面开始。

怎么用

1. 上传文件或整个文件夹 系统会先把各种格式统一转成 PDF，再按顺序合并，并保留每个文件的起始页边界。
2. 先打印第一次那份 正常单面打印就行，不用勾奇偶页。
3. 注意方向后回纸 请按你这台打印机的实际进纸方向决定是否需要调头或翻面回纸。用于第二次打印的 PDF 默认不翻转，且已自动倒序，并会在需要时自动补充空白页。
4. 再打印第二次那份 这份已经按适合手动双面的顺序处理好了，不用再手动设置翻转、倒序或补空白页。

如果原 PDF 总页数是奇数，工具会自动补一张空白背页，避免最后一张的反面错位；用于第二次打印的 PDF 默认不翻转。 多文件合并时不会做每页两版或缩印拼版；如果某个文件是奇数页，系统会在它后面自动补空白背页。
