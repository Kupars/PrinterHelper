# 我做了一个 macOS 双面打印小工具，专门拯救不支持自动双面的老打印机

如果你和我一样，还在用一些老打印机，尤其是只能单面打印、驱动也不太完善的型号，那你应该很懂这种痛苦：

- 打印双面材料时，手动选奇数页、偶数页很容易错位
- 文件一多，PDF、Word、图片、压缩包混在一起更麻烦
- 好不容易调好顺序，一次失误就得重来

所以我做了一个给 macOS 用的小工具，名字叫 **双面打印助手**。

它不是那种“理论上可以”的工具，而是专门为真实打印场景做的。目标很简单：**让不支持自动双面的打印机，也能尽量轻松地完成手动双面打印。**

---

## 它能做什么

这个工具现在已经能处理这些情况：

- 把多个文件统一整理成适合手动双面打印的 PDF
- 自动生成：
  - 第一次打印文件
  - 第二次回纸打印文件
- 自动处理奇偶页顺序，避免手动打印时页码错位
- 如果前一个文件是奇数页，会自动补空白背页
  - 这样下一个文件会从新的一张纸正面开始
  - 不会出现“上一份文件结尾和下一份文件开头印在同一张纸正反面”的问题
- 支持先上传再手动调整文件顺序

适合这些场景：

- 老式激光打印机
- 学校试卷、讲义、作业批量打印
- 老师、家长、学生整理多份资料一起打
- 家里或办公室没有自动双面功能，但又经常需要双面打印的人

---

## 使用起来是什么感觉

整个流程已经尽量做简单了：

1. 打开 `双面打印助手.app`
2. 在网页里上传文件
3. 手动拖动调整顺序
4. 生成两份打印 PDF
5. 先打印第一次
6. 把纸原方向放回去
7. 再打印第二次

也就是说，你不需要自己再去想：

- 奇数页先打还是偶数页先打
- 第二次是不是要倒序
- 总页数是奇数时要不要补空白页
- 多个文件之间会不会前后串到同一张纸上

这些事情工具都已经帮你处理好了。
